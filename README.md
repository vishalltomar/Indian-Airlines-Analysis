
# ✈️ Indian Airlines Performance & Analytics Dashboard

## 📌 Project Overview

An interactive Business Intelligence dashboard developed using Microsoft Power BI to analyze and evaluate the performance of Indian airlines through data-driven insights.

The dashboard provides a comprehensive view of passenger traffic, airline performance, customer satisfaction, operational efficiency, carbon emissions, and estimated profitability.

## 🎯 Project Objectives

- Analyze passenger traffic across different airlines.
- Evaluate airline-wise customer ratings.
- Monitor monthly passenger trends.
- Analyze aircraft seating capacity.
- Track average flight duration.
- Evaluate fuel efficiency and CO₂ emissions.
- Compare estimated profitability across airlines.

## 📊 Dashboard Features

- **Airline Performance:** Compare different Indian airlines.
- **Passenger Analysis:** Monitor total passengers and passenger capacity.
- **Customer Ratings:** Evaluate customer satisfaction.
- **Flight Duration:** Analyze average flight duration.
- **Fuel Efficiency:** Track fuel efficiency.
- **CO₂ Emissions:** Monitor carbon emissions per passenger.
- **Passenger Trends:** Visualize monthly passenger traffic.
- **Estimated Profit:** Compare airline-wise profitability.
- **Interactive Filters:** Filter data by airline and destination city.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Cleaning & Transformation
- Data Modeling
- Data Visualization

## 📈 Key Performance Indicators (KPIs)

- Total Passengers
- Passenger Capacity
- Average Customer Rating
- Average Flight Duration
- Fuel Efficiency
- CO₂ Emissions per Passenger
- Estimated Profit

1. Clone or download this repository.
2. Install Microsoft Power BI Desktop.
3. Open the `.pbix` dashboard file.
4. Explore the dashboard using interactive filters and slicers.
